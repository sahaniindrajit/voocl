# 0005: GPL-3.0 license

- **Status:** Accepted
- **Date:** 2026-11-11

## Context

Voocl is free and open source. The dictation market has many paid, closed products, and permissive licenses allow anyone to ship a closed, rebranded copy.

## Decision

License the project under **GPL-3.0**.

## Consequences

- Anyone can use, modify and redistribute Voocl, but distributed modifications must stay open source under the same license.
- New dependencies must be GPL-3.0 compatible.
- If outside contributions grow, a contributor license agreement may be added to keep licensing options open for the maintainer.
